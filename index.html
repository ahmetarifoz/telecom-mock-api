Agent evaluation

Do not just call. Correlate.

The mock data requires the agent to compare responses and arrive at the correct business decision.

01

Duplicate charge

The same roaming usage appears in two bill items. The correct dispute amount is $450.

02

Package timing

The roaming package becomes active after the usage, so the initial usage is not covered.

03

Mass outage

When a known mass outage exists, a second customer-specific trouble ticket should not be created.

04

Fiber alternative

If fiber is unavailable but DSL is serviceable, the agent should present the eligible DSL offer.

05

No coverage

If no fixed service is available, the agent must not create a quote or relocation order.

06

Explicit approval

An order or technician appointment is created only with userConfirmed: true.
